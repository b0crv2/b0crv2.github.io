Answers before you need to ask

Does my PDF leave this device?

PDF processing runs locally in your browser. This app does not upload your document or its text. The hosting provider still handles normal page requests. No analytics or advertising scripts are included.

What works in this release?

Static PDFs and fillable forms can be split by page count or explicit ranges. Form fields are fixed into the page exactly as they appear. Text-based splitting and naming require extractable text. Scans and handwriting are not OCR-processed. Signed PDFs and dynamic (XFA) forms are not supported.

How do text-based rules work?

Draw the ID area on a representative page. Consecutive pages with the same ID stay together. Draw a second area for the filename. Review every result, especially when page layouts vary. Different regions or identical IDs can cause incorrect grouping.

Are the original and the output identical?

The original file stays unchanged. Output pages are copied into new PDFs. Page appearance is intended to be preserved; document-level bookmarks, metadata, links between pages and accessibility tags may change or be lost. Keep the original and check your outputs.

Do I need an account or a subscription?

The browser demo is free. The Windows version is a separate one-time purchase. Refunds are available within 14 days of purchase, no questions asked. Your downloaded version does not expire. Future major versions and personalized document setup are not included.

Why did a filename change?

Characters unsafe for common file systems are replaced. Long names are shortened, and duplicates receive a numbered suffix. Edit any proposed filename before saving. Every save includes manifest.json with the final page-to-file mapping.

Can I process several PDFs at once?

Yes. Open up to 20 PDFs together. The same rules apply to every file, and each file gets its own subfolder. Draw areas on a representative file and check every result before saving.
