Respuestas antes de que necesites preguntar

¿Mi PDF sale de este dispositivo?

El PDF se procesa localmente en tu navegador. Esta aplicación no sube tu documento ni su texto. El proveedor de alojamiento sí gestiona las solicitudes normales de la página. No se incluyen scripts de análisis ni de publicidad.

¿Qué permite esta versión?

Los PDF estáticos y los formularios rellenables se pueden dividir por número de páginas o por rangos explícitos. Los campos de formulario se fijan en la página tal como se ven. La división y los nombres basados en texto requieren texto extraíble. No se aplica OCR a documentos escaneados ni manuscritos. No se admiten PDF firmados ni formularios dinámicos (XFA).

¿Cómo funcionan las reglas basadas en texto?

Marca el área del ID en una página representativa. Las páginas consecutivas con el mismo ID permanecen juntas. Marca una segunda área para el nombre del archivo. Revisa cada resultado, especialmente si varía el diseño de las páginas. Las áreas diferentes o los ID idénticos pueden causar agrupaciones incorrectas.

¿El original y el resultado son idénticos?

El archivo original no cambia. Las páginas de salida se copian en PDF nuevos. Se busca conservar su apariencia; los marcadores, los metadatos, los enlaces entre páginas y las etiquetas de accesibilidad del documento pueden cambiar o perderse. Conserva el original y revisa los resultados.

¿Necesito una cuenta o una suscripción?

La demo del navegador es gratuita. La versión para Windows es una compra única independiente. Puedes solicitar el reembolso dentro de los 14 días posteriores a la compra, sin preguntas. La versión descargada no caduca. No se incluyen futuras versiones principales ni la configuración personalizada de documentos.

¿Por qué ha cambiado un nombre de archivo?

Se sustituyen los caracteres no seguros para los sistemas de archivos habituales. Los nombres largos se acortan y los duplicados reciben un sufijo numerado. Puedes editar cualquier nombre propuesto antes de guardar. Cada guardado incluye manifest.json con la correspondencia final entre páginas y archivos.

¿Puedo procesar varios PDF a la vez?

Sí. Abre hasta 20 PDF juntos. Las mismas reglas se aplican a todos los archivos, y cada archivo tiene su propia subcarpeta. Dibuja las áreas en un archivo representativo y revisa todos los resultados antes de guardar.
