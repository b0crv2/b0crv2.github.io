Des réponses avant même de poser la question

Mon PDF quitte-t-il cet appareil ?

Le PDF est traité localement dans votre navigateur. Cette application n’envoie ni votre document ni son texte sur un serveur. L’hébergeur traite toutefois les requêtes normales de la page. Aucun script d’analyse d’audience ou de publicité n’est inclus.

Que permet cette version ?

Les PDF statiques et les formulaires à remplir peuvent être séparés par nombre de pages ou par plages explicites. Les champs de formulaire sont figés dans la page tels qu’ils apparaissent. La séparation et le nommage fondés sur le texte nécessitent du texte extractible. Les documents numérisés et manuscrits ne sont pas traités par OCR. Les PDF signés et les formulaires dynamiques (XFA) ne sont pas pris en charge.

Comment fonctionnent les règles fondées sur le texte ?

Délimitez la zone de l’identifiant sur une page représentative. Les pages consécutives ayant le même identifiant restent ensemble. Délimitez une seconde zone pour le nom de fichier. Vérifiez chaque résultat, surtout si la mise en page varie. Des zones différentes ou des identifiants identiques peuvent entraîner un regroupement incorrect.

L’original et le résultat sont-ils identiques ?

Le fichier original reste inchangé. Les pages de sortie sont copiées dans de nouveaux PDF. Leur apparence doit être conservée, mais les signets du document, les métadonnées, les liens entre pages et les balises d’accessibilité peuvent être modifiés ou perdus. Conservez l’original et vérifiez les résultats.

Faut-il un compte ou un abonnement ?

La démo dans le navigateur est gratuite. La version Windows fait l’objet d’un achat unique distinct. Vous pouvez être remboursé sous 14 jours après l’achat, sans justification. Votre version téléchargée n’expire pas. Les futures versions majeures et la configuration personnalisée des documents ne sont pas incluses.

Pourquoi un nom de fichier a-t-il changé ?

Les caractères incompatibles avec les systèmes de fichiers courants sont remplacés. Les noms longs sont raccourcis et les doublons reçoivent un suffixe numéroté. Vous pouvez modifier tout nom proposé avant l’enregistrement. Chaque enregistrement contient manifest.json avec la correspondance finale entre pages et fichiers.

Puis-je traiter plusieurs PDF à la fois ?

Oui. Ouvrez jusqu’à 20 PDF ensemble. Les mêmes règles s’appliquent à chaque fichier, et chaque fichier obtient son propre sous-dossier. Tracez les zones sur un fichier représentatif et vérifiez chaque résultat avant l’enregistrement.
