PDF-Dateien nach Kundentext benennen

Nützliche Dateinamen verbinden eine stabile Dokument-ID mit einem wiedererkennbaren Namen. INV-1041_North Studio.pdf lässt sich zum Beispiel leichter sortieren als scan001.pdf. Das Beispiel verwendet fiktive Daten.

Den Text für den Dateinamen auswählen

  1. Öffnen Sie eine PDF und legen Sie die Seitengruppen fest.
  2. Markieren Sie den Bereich mit dem Kundennamen oder der Referenz, die Sie verwenden möchten.
  3. Prüfen Sie den vorgeschlagenen Namen für jede Ausgabe. Die erste Seite einer Gruppe sollte den gewünschten Text enthalten.
  4. Bearbeiten Sie einzelne Ausgabenamen vor dem Export, wenn die Vorlage uneinheitlich ist.

Dateinamen sicher behandeln

Windows verbietet einige Zeichen in Dateinamen. Paperlane bereinigt Namen, passt reservierte Namen an und fügt Suffixe hinzu, wenn Namen kollidieren. So wird verhindert, dass eine spätere PDF eine frühere in der Ausgabe-ZIP unbemerkt ersetzt. Ein wiederholter Kundenname ist normal; behalten Sie also die Dokument-ID, wenn Sie unterscheidbare Dateien brauchen.

Die Vorschau lesen

Ein Auswahlrahmen, der Beschriftungen oder Nachbarspalten einschließt, kann unsaubere Namen erzeugen. Verkleinern Sie den Rahmen und prüfen Sie mehr als eine Seite. Enthält das Dokument nur ein Bild, geben Sie die Namen selbst ein; Paperlane leitet Namen nicht über einen KI-Dienst ab.

Vor dem Weitergeben prüfen

Dateinamen können Kundeninformationen preisgeben, auch wenn die PDF anderswo verschlüsselt ist. Speichern und teilen Sie die Ausgabe nach den Regeln Ihrer Organisation. Die Übersichtsdatei (manifest.json) gehört ebenfalls zur Ausgabe und kann die gewählten Namen enthalten.
