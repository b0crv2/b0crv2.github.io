Regeln für wiederkehrende Dokumente speichern und wiederverwenden

Wenn die Abrechnung jeden Monat dasselbe Layout hat, kann eine gespeicherte Regel die wiederholte Einrichtung verringern. Sie speichert Verarbeitungseinstellungen und ausgewählte Bereiche, nicht die Original-PDF. Bewahren Sie die Regeldatei auf Ihrem eigenen Gerät auf.

Eine Regel aus einem geprüften Beispiel erstellen

  1. Wählen Sie eine repräsentative PDF und richten Sie die Bereiche für Gruppierung und Dateinamen ein.
  2. Prüfen Sie jede Grenze und einige Namen in der Vorschau, auch auf Folgeseiten.
  3. Laden Sie über „Regeln speichern“ eine JSON-Regeldatei herunter.
  4. Geben Sie der Regel einen aussagekräftigen Namen, der die Dokumentvorlage kennzeichnet.

Auf einen neuen Stapel anwenden

Öffnen Sie die nächste PDF und laden Sie die gespeicherte Regel. Prüfen Sie die extrahierten Schlüssel und Ausgabenamen erneut. Die Wiederverwendung einer Regel beweist nicht, dass das neue Layout, die Textkodierung oder die Seitenmaße übereinstimmen.

Wann eine neue Regel nötig ist

Erstellen Sie eine eigene Regel, wenn ein Aussteller Felder verschiebt, die Seitengröße ändert oder verschiedene Vorlagen mischt. Fehlt die Dokument-ID oder erscheint sie uneinheitlich, verwenden Sie explizite Seitenbereiche und prüfen Sie das Ergebnis, statt einem veralteten Bereich zu vertrauen.

Supportaufwand verringern

Bewahren Sie je Vorlage ein kleines fiktives oder geschwärztes Testdokument auf. Testen Sie es nach jeder Regeländerung. Der Windows-Download läuft nach dem Entpacken lokal; er braucht kein Abonnement, keinen KI-Schlüssel und kein Konto für Cloud-Verarbeitung.
