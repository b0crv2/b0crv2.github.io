Einen Stapel Rechnungen nach Dokument-ID aufteilen

Ein Stapel enthält oft einseitige und mehrseitige Rechnungen zugleich. Wird jede Seite einzeln abgetrennt, entstehen unvollständige Dokumente. Paperlane kann eine wiederholte Rechnungs-ID nutzen, um aufeinanderfolgende Seiten zusammenzuhalten.

Ein repräsentatives Beispiel vorbereiten

Verwenden Sie zuerst das integrierte sechsseitige Beispiel: INV-1041 steht auf den Seiten 1–2, INV-1042 auf Seite 3 und INV-1043 auf den Seiten 4–6. Prüfen Sie bei Ihrer eigenen PDF, dass die ID markierbarer Text ist und an derselben Stelle erscheint. Gescannte Bilder benötigen anderswo OCR oder eine seitenbasierte Aufteilung.

Den Gruppierungsschlüssel auswählen

  1. Öffnen Sie die PDF und wählen Sie den Gruppierungsmodus nach Textänderung.
  2. Ziehen Sie den Schlüsselbereich eng um die Dokument-ID. Vermeiden Sie Seitenzähler oder ein nicht dazugehöriges Datum.
  3. Prüfen Sie den extrahierten Schlüssel in der Vorschau auf mehreren Seiten und kontrollieren Sie die vorgeschlagenen Grenzen.
  4. Sehen Sie nach, was auf einer Seite mit leerem Schlüssel passiert. Hängen Sie Folgeseiten nur an, wenn das dem tatsächlichen Dokument entspricht.

Die Grenzregel verstehen

Die Gruppierung folgt aufeinanderfolgenden Seiten: A, A, B, A ergibt drei Gruppen, nicht eine zusammengeführte Menge aller A-Seiten. Wenn eine Rechnung auf einer Seite ohne ihre ID weitergeht, prüfen Sie diese Grenze manuell. Wandert die ID zwischen den Seiten, verwenden Sie explizite Bereiche, statt anzunehmen, dass derselbe Rahmen auf jede Seite passt.

Das Ergebnis prüfen

Exportieren Sie die ZIP, öffnen Sie jede PDF und vergleichen Sie erste und letzte Seite mit der Quelle. Die Übersichtsdatei (manifest.json) hält die Zuordnung der Quellseiten fest. Behalten Sie das Original; die Prüfung der Seitenkopie garantiert nicht, dass alle Anmerkungen, Lesezeichen oder Barrierefreiheitsfunktionen erhalten bleiben.
