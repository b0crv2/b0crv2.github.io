Name PDF files from customer text

Useful filenames combine a stable document identifier with a recognizable name. For example, INV-1041_North Studio.pdf is easier to sort than scan001.pdf. The example uses fictional data.

Select the filename text

  1. Open a PDF and establish its page groups.
  2. Select the region containing the customer name or reference you want to use.
  3. Check the proposed name for each output. The first page of a group should contain the intended text.
  4. Edit individual output names before exporting if the template is inconsistent.

Handle filenames safely

Windows forbids some characters in filenames. Paperlane sanitizes names, adjusts reserved names and adds suffixes when names collide. This prevents a later PDF from silently replacing an earlier one in the output ZIP. A repeated customer name is normal, so keep the document ID when you need distinct files.

Read the preview

A selection box that includes labels or neighboring columns can create noisy names. Tighten the box and inspect more than one page. If the document contains only an image, type the names yourself; Paperlane does not infer names with an AI service.

Check before sharing

Filenames can reveal customer information even when the PDF is encrypted elsewhere. Store and share the output according to your organization's rules. The manifest is also part of the output and may contain the chosen names.
