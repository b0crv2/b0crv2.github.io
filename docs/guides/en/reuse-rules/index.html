Save and reuse rules for recurring documents

If each month's statement uses the same layout, a saved rule can reduce repeated setup. It stores processing settings and selected regions, not the original PDF. Keep the rule file on your own device.

Create a rule from a checked example

  1. Choose a representative PDF and configure grouping and filename regions.
  2. Preview every boundary and a few names, including continuation pages.
  3. Use the save-rule control to download a JSON rule file.
  4. Give the rule a descriptive name that identifies the document template.

Apply it to a new batch

Open the next PDF and load the saved rule. Review its extracted keys and output names again. Reusing a rule does not prove that the new layout, text encoding or page dimensions match.

When to create a new rule

Create a separate rule if an issuer moves fields, changes page size or combines different templates. If the document ID is missing or appears inconsistently, use explicit page ranges and review the result rather than trusting an outdated region.

Reduce support work

Keep one small fictional or redacted test document per template. Test it after changing a rule. The Windows download works locally after extraction; it does not need a subscription, AI key or cloud processing account.
