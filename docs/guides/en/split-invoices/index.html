Split a batch of invoices by document ID

A batch often contains one-page and multi-page invoices together. Splitting every page creates incomplete documents. Paperlane can use a repeated invoice ID to keep consecutive pages together.

Prepare a representative example

Use the built-in six-page example first: INV-1041 appears on pages 1–2, INV-1042 on page 3 and INV-1043 on pages 4–6. With your own PDF, confirm that the ID is selectable text and appears in the same place. Scanned images need OCR elsewhere or page-based splitting.

Select the grouping key

  1. Open the PDF and choose the text-change grouping mode.
  2. Draw the key region tightly around the document ID. Avoid a page counter or unrelated date.
  3. Preview the extracted key on several pages and check the proposed boundaries.
  4. Review what happens on a page with a blank key. Attach continuation pages only when this matches the actual document.

Understand the boundary rule

Grouping follows consecutive pages: A, A, B, A produces three groups, not a merged set of all A pages. If an invoice continues on a page without its ID, inspect that boundary manually. If IDs move between pages, use explicit ranges rather than assuming the same box fits every page.

Verify the result

Export the ZIP, open each PDF and compare the first and last pages with the source. The manifest records source-page assignments. Keep the original; page-copy validation does not guarantee every annotation, bookmark or accessibility feature is preserved.
