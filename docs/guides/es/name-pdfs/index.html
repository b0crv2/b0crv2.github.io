Nombrar archivos PDF a partir del texto del cliente

Un nombre de archivo útil combina un identificador de documento estable con un nombre reconocible. Por ejemplo, INV-1041_North Studio.pdf es más fácil de ordenar que scan001.pdf. El ejemplo usa datos ficticios.

Selecciona el texto para el nombre del archivo

  1. Abre un PDF y define sus grupos de páginas.
  2. Selecciona la región que contiene el nombre del cliente o la referencia que quieres usar.
  3. Comprueba el nombre propuesto para cada salida. La primera página de un grupo debe contener el texto deseado.
  4. Edita los nombres de salida individuales antes de exportar si la plantilla no es uniforme.

Gestiona los nombres de archivo con seguridad

Windows prohíbe algunos caracteres en los nombres de archivo. Paperlane limpia los nombres, ajusta los nombres reservados y añade sufijos cuando los nombres coinciden. Así se evita que un PDF posterior reemplace en silencio a uno anterior en el ZIP de salida. Que un nombre de cliente se repita es normal, así que conserva el ID del documento cuando necesites archivos distintos.

Lee la vista previa

Un recuadro de selección que incluya etiquetas o columnas vecinas puede generar nombres con texto sobrante. Ajusta el recuadro y revisa más de una página. Si el documento solo contiene una imagen, escribe los nombres manualmente; Paperlane no deduce nombres con un servicio de IA.

Comprueba antes de compartir

Los nombres de archivo pueden revelar información del cliente aunque el PDF esté cifrado en otro lugar. Guarda y comparte la salida según las normas de tu organización. El archivo manifest.json también forma parte de la salida y puede contener los nombres elegidos.
