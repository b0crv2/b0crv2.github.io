Guardar y reutilizar reglas para documentos recurrentes

Si el extracto de cada mes usa el mismo diseño, una regla guardada puede reducir la configuración repetida. La regla guarda los ajustes de procesamiento y las regiones seleccionadas, no el PDF original. Conserva el archivo de reglas en tu propio dispositivo.

Crea una regla a partir de un ejemplo comprobado

  1. Elige un PDF representativo y configura las regiones de agrupación y de nombre de archivo.
  2. Previsualiza cada límite y algunos nombres, incluidas las páginas de continuación.
  3. Usa el botón «Guardar reglas» para descargar un archivo de reglas JSON.
  4. Dale a la regla un nombre descriptivo que identifique la plantilla del documento.

Aplícala a un lote nuevo

Abre el siguiente PDF y carga la regla guardada. Revisa de nuevo las claves extraídas y los nombres de salida. Reutilizar una regla no demuestra que el nuevo diseño, la codificación del texto o las dimensiones de página coincidan.

Cuándo crear una regla nueva

Crea una regla aparte si un emisor mueve campos, cambia el tamaño de página o combina plantillas distintas. Si el ID del documento falta o aparece de forma irregular, usa rangos de páginas explícitos y revisa el resultado en lugar de confiar en una región desactualizada.

Reduce el trabajo de soporte

Conserva, por cada plantilla, un documento de prueba pequeño, ficticio o con los datos ocultados. Pruébalo después de cambiar una regla. La descarga para Windows funciona localmente tras extraerla; no necesita suscripción, clave de IA ni cuenta de procesamiento en la nube.
