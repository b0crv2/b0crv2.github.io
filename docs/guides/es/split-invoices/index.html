Dividir un lote de facturas por ID de documento

Un lote suele mezclar facturas de una página con facturas de varias páginas. Dividir cada página crea documentos incompletos. Paperlane puede usar un ID de factura repetido para mantener juntas las páginas consecutivas.

Prepara un ejemplo representativo

Empieza con el ejemplo integrado de seis páginas: INV-1041 aparece en las páginas 1–2, INV-1042 en la página 3 e INV-1043 en las páginas 4–6. Con tu propio PDF, comprueba que el ID sea texto seleccionable y que aparezca en el mismo lugar. Las imágenes escaneadas necesitan OCR en otra herramienta o una división por número de páginas.

Selecciona la clave de agrupación

  1. Abre el PDF y elige el modo de agrupación por cambio de texto.
  2. Dibuja el área del ID del documento bien ajustada al ID. Evita el contador de páginas o fechas sin relación.
  3. Previsualiza la clave extraída en varias páginas y revisa los límites propuestos.
  4. Revisa qué ocurre en una página con la clave vacía. Añade las páginas sin ID al documento anterior solo cuando esto coincida con el documento real.

Entiende la regla de los límites

La agrupación sigue páginas consecutivas: A, A, B, A produce tres grupos, no un conjunto fusionado de todas las páginas A. Si una factura continúa en una página sin su ID, revisa ese límite manualmente. Si los ID cambian de posición entre páginas, usa rangos explícitos en lugar de suponer que el mismo recuadro sirve para todas las páginas.

Verifica el resultado

Exporta el ZIP, abre cada PDF y compara la primera y la última página con el original. El archivo manifest.json registra qué páginas de origen corresponden a cada archivo. Conserva el original; la validación de copia de páginas no garantiza que se conserven todas las anotaciones, marcadores o funciones de accesibilidad.
