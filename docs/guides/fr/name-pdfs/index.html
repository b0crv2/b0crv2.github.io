Nommer des fichiers PDF à partir du texte client

Un nom de fichier utile associe un identifiant de document stable à un nom reconnaissable. Par exemple, INV-1041_North Studio.pdf se trie plus facilement que scan001.pdf. L’exemple utilise des données fictives.

Sélectionner le texte du nom de fichier

  1. Ouvrez un PDF et définissez ses groupes de pages.
  2. Sélectionnez la zone contenant le nom du client ou la référence à utiliser.
  3. Vérifiez le nom proposé pour chaque sortie. La première page d’un groupe doit contenir le texte voulu.
  4. Modifiez les noms de sortie individuellement avant l’export si le modèle n’est pas homogène.

Gérer les noms de fichiers en toute sécurité

Windows interdit certains caractères dans les noms de fichiers. Paperlane nettoie les noms, ajuste les noms réservés et ajoute des suffixes en cas de collision. Cela évite qu’un PDF ultérieur remplace silencieusement un PDF précédent dans le ZIP de sortie. Un nom de client répété est normal ; conservez donc l’identifiant du document quand vous avez besoin de fichiers distincts.

Lire l’aperçu

Un cadre de sélection qui inclut des libellés ou des colonnes voisines peut produire des noms parasités. Resserrez le cadre et examinez plus d’une page. Si le document ne contient qu’une image, saisissez les noms vous-même ; Paperlane ne déduit pas les noms via un service d’IA.

Vérifier avant de partager

Les noms de fichiers peuvent révéler des informations client même si le PDF est chiffré ailleurs. Stockez et partagez la sortie selon les règles de votre organisation. Le fichier récapitulatif (manifest.json) fait aussi partie de la sortie et peut contenir les noms choisis.
