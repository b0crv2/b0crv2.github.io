顧客名などの文字からPDFファイル名を付ける

使いやすいファイル名は、変わらない書類IDと見分けやすい名前の組み合わせです。たとえばINV-1041_North Studio.pdfは、scan001.pdfより並べ替えが簡単です。この例は架空のデータです。

ファイル名に使う文字を選ぶ

  1. PDFを開き、ページのグループを決めます。
  2. 使いたい顧客名や参照番号が入っている範囲を選択します。
  3. 各出力に提案された名前を確認します。グループの最初のページに目的の文字が含まれている必要があります。
  4. テンプレートが一定でない場合は、書き出す前に個々の出力名を編集します。

ファイル名を安全に扱う

Windowsではファイル名に使えない文字があります。Paperlaneは名前を整え、予約名を調整し、名前が重なるときは末尾に番号を付けます。これにより、出力ZIPの中で後のPDFが前のPDFを気づかないうちに上書きしてしまうのを防ぎます。同じ顧客名が繰り返されるのは普通なので、別々のファイルが必要なときは書類IDを残してください。

プレビューを確認する

選択枠にラベルや隣の列が入ると、名前に余計な文字が混ざります。枠を狭め、複数のページで確認してください。書類が画像だけの場合は名前を自分で入力してください。PaperlaneはAIサービスで名前を推測しません。

共有する前に確認する

PDFが別の場所で暗号化されていても、ファイル名から顧客情報が分かることがあります。出力は組織のルールに従って保管・共有してください。一覧ファイル（manifest.json）も出力の一部で、選んだ名前が含まれることがあります。
