繰り返しの書類向けにルールを保存して再利用する

毎月の明細書が同じレイアウトなら、保存したルールで繰り返しの設定を減らせます。ルールには処理設定と選択した範囲が保存され、元のPDFは含まれません。ルールファイルはご自身の端末に保管してください。

確認済みの例からルールを作る

  1. 代表的なPDFを選び、グループ化とファイル名の範囲を設定します。
  2. すべての区切りといくつかの名前を、続きのページも含めて確認します。
  3. 「ルールを保存」ボタンでJSON形式のルールファイルをダウンロードします。
  4. 書類のテンプレートが分かる、説明的な名前をルールに付けます。

新しいバッチに適用する

次のPDFを開き、保存したルールを読み込みます。抽出された書類IDと出力名をもう一度確認してください。ルールを再利用しても、新しいレイアウト・文字エンコード・ページ寸法が一致している証明にはなりません。

新しいルールを作るべきとき

発行元が項目の位置を変えた、ページサイズを変えた、複数のテンプレートを混ぜた場合は、別のルールを作ってください。書類IDが欠けていたり位置が一定でないときは、古い範囲を信用せず、明示的なページ範囲を使って結果を確認してください。

手間を減らす

テンプレートごとに、架空または伏せ字にした小さなテスト書類を1つ用意してください。ルールを変更したらそれで試します。Windows版は展開後にローカルで動作し、定期購入・AIキー・クラウド処理アカウントは不要です。
