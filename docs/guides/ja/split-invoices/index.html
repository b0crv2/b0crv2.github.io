書類IDで請求書の束を分割する

1つのファイルに1ページの請求書と複数ページの請求書が混在していることはよくあります。すべてのページを1枚ずつ分けると、書類が不完全になります。Paperlaneでは、繰り返し現れる請求書IDを基準に、連続するページをひとまとまりに保てます。

代表的な例で準備する

まず内蔵の6ページの例で試してください。INV-1041は1〜2ページ、INV-1042は3ページ、INV-1043は4〜6ページにあります。ご自身のPDFでは、IDが選択できる文字であり、各ページの同じ位置にあることを確認してください。スキャン画像には別途OCRか、ページ数基準の分割が必要です。

分割の基準を選ぶ

  1. PDFを開き、分割方法で「選択した文字が変わる位置」を選びます。
  2. 書類IDだけをぴったり囲むように範囲を描きます。ページ番号や無関係な日付が入らないようにします。
  3. 複数のページで抽出された書類IDを確認し、提案された区切りを点検します。
  4. IDが空のページがどう扱われるかを確認します。「IDが空のページを直前の書類に追加」を使うのは、実際の書類構造に合う場合だけにしてください。

区切りのルールを理解する

グループ化は連続するページ単位で行われます。A, A, B, Aの順なら結果は3つのグループで、すべてのAページが1つに統合されることはありません。IDのないページに請求書が続く場合は、その区切りを手動で確認してください。IDの位置がページごとに変わる場合は、同じ枠がすべてのページに合うと仮定せず、明示的なページ範囲を使ってください。

結果を確認する

ZIPをダウンロードし、各PDFを開いて最初と最後のページを元のファイルと比べてください。一覧ファイル（manifest.json）には元ページの割り当てが記録されます。元のファイルは保管してください。ページのコピー検証は、注釈・しおり・アクセシビリティ機能がすべて保持されることを保証するものではありません。
