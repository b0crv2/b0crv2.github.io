고객명으로 PDF 파일명 자동 지정하기

파일명에 문서 번호와 식별 가능한 이름을 함께 쓰면 정리가 쉬워집니다. 예를 들어 가상의 INV-1041_North Studio.pdf는 scan001.pdf보다 내용을 알아보기 쉽습니다.

파일명에 넣을 글자 선택하기

  1. PDF를 열고 먼저 페이지 묶음을 정합니다.
  2. 고객명이나 문서 참조값이 있는 영역을 선택합니다.
  3. 각 출력 파일의 예상 이름을 확인합니다. 묶음의 첫 페이지에 원하는 글자가 있어야 합니다.
  4. 서식이 일정하지 않으면 내려받기 전에 각 파일명을 직접 수정합니다.

중복과 금지 문자 처리

Windows에서 허용하지 않는 문자는 정리하고 예약된 이름은 조정합니다. 같은 이름이 생기면 구분용 접미사를 붙여 ZIP 안에서 덮어쓰지 않도록 합니다. 고객명이 반복될 수 있으므로 개별 문서 구분에는 문서 번호를 함께 사용하는 편이 좋습니다.

예상 결과 읽기

영역에 제목이나 옆 열이 함께 들어가면 불필요한 글자가 이름에 포함될 수 있습니다. 영역을 좁히고 여러 페이지를 확인하세요. 그림뿐인 스캔은 이름을 직접 입력해야 하며 AI로 자동 추측하지 않습니다.

공유 전에 확인하기

파일명 자체에도 고객 정보가 포함될 수 있습니다. 출력 PDF와 함께 저장되는 목록 파일도 조직의 보관·공유 기준에 맞게 관리하세요.
