반복 서류의 분리 규칙 저장과 재사용

매달 같은 서식의 명세서를 받는다면 규칙을 저장해 반복 설정을 줄일 수 있습니다. 규칙 파일에는 처리 설정과 선택 영역이 담기며 원본 PDF는 담기지 않습니다. 규칙은 사용자 기기에 보관합니다.

검토한 예제로 규칙 만들기

  1. 대표 PDF에서 묶음 방식과 파일명 영역을 지정합니다.
  2. 후속 페이지를 포함해 모든 분리 경계와 예상 이름을 확인합니다.
  3. 규칙 저장 버튼으로 JSON 파일을 내려받습니다.
  4. 어떤 서식용인지 알 수 있도록 규칙 파일 이름을 정합니다.

새 파일에 적용하기

다음 PDF를 열고 저장한 규칙을 불러옵니다. 추출값과 예상 파일명을 다시 검토하세요. 규칙을 불러왔다는 사실만으로 새 파일의 배치·글자 인코딩·페이지 크기가 같다는 보장은 없습니다.

규칙을 새로 만들어야 할 때

발급처가 항목 위치를 옮기거나 페이지 크기를 바꾸거나 여러 서식을 섞었다면 규칙을 구분하세요. 문서 번호가 누락되거나 불규칙하면 명시적 페이지 범위를 지정하고 결과를 확인하는 편이 낫습니다.

반복 작업 줄이기

서식별로 가상 정보 또는 적절히 비식별화한 작은 테스트 문서를 준비해 두고 규칙을 바꿀 때 확인하세요. Windows 다운로드판은 압축을 푼 후 로컬에서 실행되며 구독이나 AI 키가 필요하지 않습니다.
