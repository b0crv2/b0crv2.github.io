문서 번호로 여러 페이지 청구서 나누기

한 파일에 1페이지 청구서와 여러 페이지 청구서가 섞여 있으면 한 페이지씩 자르는 것만으로는 문서가 완성되지 않습니다. 반복되는 문서 번호를 기준으로 연속 페이지를 묶을 수 있습니다.

먼저 예제로 확인하기

기본 예제의 INV-1041은 1–2페이지, INV-1042는 3페이지, INV-1043은 4–6페이지에 있습니다. 직접 사용할 파일은 문서 번호의 글자를 선택할 수 있고 페이지마다 같은 위치에 있는지 확인하세요. 스캔에는 별도 OCR 또는 페이지 수 기준 분리가 필요합니다.

분리 기준 선택하기

  1. PDF를 열고 글자 변경 기준의 분리 방식을 선택합니다.
  2. 문서 번호만 포함하도록 기준 영역을 그립니다. 페이지 번호나 날짜가 섞이지 않게 합니다.
  3. 여러 페이지에서 추출값을 확인하고 분리 경계를 검토합니다.
  4. 기준이 비어 있는 후속 페이지를 앞 문서에 붙이는 설정은 실제 문서 구조에 맞을 때만 사용합니다.

같은 번호라도 연속 여부가 중요합니다

A, A, B, A 순서라면 결과는 세 묶음입니다. 떨어져 있는 A를 하나로 합치는 기능은 아닙니다. 번호의 위치가 바뀌거나 누락되는 문서는 명시적 페이지 범위를 사용하는 것이 낫습니다.

결과 검토하기

ZIP을 풀어 각 PDF의 첫 페이지와 마지막 페이지를 원본과 비교하세요. 함께 저장되는 목록에는 원본 페이지와 출력 파일의 대응이 기록됩니다. 원본은 보관하고 책갈피·접근성 구조 등 필요한 요소가 유지되는지 별도로 확인하세요.
