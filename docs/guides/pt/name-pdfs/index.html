Nomear arquivos PDF a partir do texto do cliente

Nomes de arquivo úteis combinam um identificador de documento estável com um nome reconhecível. Por exemplo, INV-1041_North Studio.pdf é mais fácil de ordenar do que scan001.pdf. O exemplo usa dados fictícios.

Selecione o texto para o nome do arquivo

  1. Abra um PDF e defina os seus grupos de páginas.
  2. Selecione a região que contém o nome do cliente ou a referência que deseja usar.
  3. Confira o nome proposto para cada saída. A primeira página de um grupo deve conter o texto pretendido.
  4. Edite os nomes de saída individualmente antes de exportar se o modelo não for uniforme.

Trate os nomes de arquivo com segurança

O Windows proíbe alguns caracteres em nomes de arquivo. O Paperlane limpa os nomes, ajusta nomes reservados e adiciona sufixos quando há colisão. Isso impede que um PDF posterior substitua silenciosamente um anterior no ZIP de saída. Um nome de cliente repetido é normal, por isso mantenha o ID do documento quando precisar de arquivos distintos.

Leia a prévia

Uma área de seleção que inclua rótulos ou colunas vizinhas pode gerar nomes com texto a mais. Ajuste a área e inspecione mais de uma página. Se o documento contiver apenas uma imagem, digite os nomes você mesmo; o Paperlane não deduz nomes com um serviço de IA.

Verifique antes de compartilhar

Nomes de arquivo podem revelar informações do cliente mesmo que o PDF esteja criptografado em outro lugar. Armazene e compartilhe a saída conforme as regras da sua organização. O arquivo manifest.json também faz parte da saída e pode conter os nomes escolhidos.
