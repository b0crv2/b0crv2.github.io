Salvar e reutilizar regras para documentos recorrentes

Se o extrato de cada mês usa o mesmo layout, uma regra salva pode reduzir a configuração repetida. Ela armazena as configurações de processamento e as regiões selecionadas, não o PDF original. Guarde o arquivo de regras no seu próprio dispositivo.

Crie uma regra a partir de um exemplo conferido

  1. Escolha um PDF representativo e configure as regiões de agrupamento e de nome de arquivo.
  2. Visualize cada limite e alguns nomes, incluindo páginas de continuação.
  3. Use o botão “Salvar regras” para baixar um arquivo de regras JSON.
  4. Dê à regra um nome descritivo que identifique o modelo do documento.

Aplique-a a um novo lote

Abra o próximo PDF e carregue a regra salva. Revise novamente as chaves extraídas e os nomes de saída. Reutilizar uma regra não prova que o novo layout, a codificação do texto ou as dimensões da página coincidam.

Quando criar uma nova regra

Crie uma regra separada se um emissor mover campos, mudar o tamanho da página ou combinar modelos diferentes. Se o ID do documento estiver ausente ou aparecer de forma inconsistente, use intervalos de páginas explícitos e revise o resultado em vez de confiar em uma região desatualizada.

Reduza o trabalho de suporte

Mantenha, para cada modelo, um pequeno documento de teste fictício ou com dados ocultados. Teste-o após alterar uma regra. O download para Windows funciona localmente após a extração; não precisa de assinatura, chave de IA nem conta de processamento em nuvem.
