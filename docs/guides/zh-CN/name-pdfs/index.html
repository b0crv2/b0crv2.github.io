用客户名称等文字为 PDF 文件命名

好用的文件名由稳定的文档编号和容易辨认的名称组成。例如，INV-1041_North Studio.pdf 比 scan001.pdf 更容易排序。示例使用的是虚构数据。

选择用作文件名的文字

  1. 打开 PDF，先确定页面分组。
  2. 选中包含客户名称或参考号的区域。
  3. 检查每个输出的建议名称。分组的第一页应包含所需的文字。
  4. 如果版式不一致，请在导出前逐个修改输出名称。

安全地处理文件名

Windows 禁止在文件名中使用某些字符。Paperlane 会清理名称、调整保留名称，并在重名时添加后缀。这样可以避免后面的 PDF 在输出 ZIP 中悄悄覆盖前面的 PDF。客户名称重复很常见，因此需要区分文件时请保留文档编号。

查看预览

如果选框包含了标签或相邻的列，名称里会混入多余文字。请缩小选框，并检查多个页面。如果文档只有图片，请自行输入名称；Paperlane 不会借助 AI 服务推断名称。

分享前检查

即使 PDF 在别处已加密，文件名仍可能泄露客户信息。请按照所在机构的规定保存和分享输出结果。清单文件（manifest.json）也是输出的一部分，可能包含所选的名称。
