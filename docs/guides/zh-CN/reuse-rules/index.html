为重复出现的文档保存并复用规则

如果每月的对账单版式相同，保存的规则可以减少重复设置。规则保存的是处理设置和所选区域，不包含原始 PDF。请把规则文件保存在自己的设备上。

用检查过的示例创建规则

  1. 选择一份有代表性的 PDF，设置分组和文件名区域。
  2. 预览每个分界和若干名称，包括后续页面。
  3. 点击“保存规则”下载 JSON 规则文件。
  4. 给规则起一个能说明文档版式的描述性名称。

应用到新的一批文件

打开下一份 PDF，加载保存的规则。再次检查提取出的编号和输出名称。复用规则并不能证明新文件的版式、文字编码或页面尺寸与之前一致。

何时需要新建规则

如果开票方移动了字段位置、更改了页面大小或混用了不同版式，请另建规则。如果文档编号缺失或位置不固定，请使用明确的页面范围并核对结果，而不是信赖过时的区域。

减少后续麻烦

为每种版式保留一份小的虚构或已遮盖信息的测试文档。修改规则后用它测试。Windows 版解压后即可在本地运行，不需要订阅、AI 密钥或云端处理账户。
