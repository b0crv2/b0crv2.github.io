Help & support

Start with the sample

Open the demo and choose the built-in example. It contains six pages and three fictional invoice IDs. Preview the proposed names and groups, then save. The sample is exempt from the demo's three-input-page export limit.

Your own PDFs

Use static PDFs with selectable text; fillable forms are also accepted and their field values are fixed into the page as shown. The demo can preview up to 300 pages and 50 MB per file; export is available when your own files total at most three pages. Drawing a box selects text from the same location on every page. Check every proposed group before saving.

Windows download

Extract the whole purchased ZIP into a normal folder (for example Desktop or Documents) and open Start-Paperlane.cmd. It starts a small server that only this PC can reach and opens your browser. If another program already uses a port, Paperlane picks a free one automatically. Use Stop-Paperlane.cmd when finished. Open up to 20 PDFs at once and save into a new folder (existing files are never overwritten) or a ZIP. A current Chrome or Edge browser is required; there is no installation or account. Follow your organization's software policies if a managed computer blocks scripts.

Common problems

  • No text found: a scan or outlined lettering has no selectable text. Use page-count or explicit-range splitting and type filenames. OCR is not included.
  • Wrong grouping: choose a stable document ID rather than a page number. A new group starts when the selected key changes. Review blank-key handling and all boundaries.
  • Rejected PDF: encrypted, digitally signed and dynamic (XFA) PDFs, embedded attachments and active content are unsupported. Keep the original; obtain a static copy from its author when appropriate.
  • Unexpected filename: prohibited characters are replaced, reserved Windows names are adjusted, and duplicate names receive a suffix. Review the editable names before saving.
  • Missing bookmark or accessibility structure: these structures are not guaranteed to survive page copying.
