Jawaban sebelum Anda perlu bertanya

Apakah PDF saya keluar dari perangkat ini?

Pemrosesan PDF berjalan secara lokal di browser. Aplikasi ini tidak mengunggah dokumen atau teksnya. Penyedia hosting tetap menangani permintaan halaman biasa. Tidak ada skrip analitik atau iklan.

Apa yang dapat dilakukan versi ini?

PDF statis dan formulir isian dapat dipisahkan menurut jumlah halaman atau rentang tertentu. Kolom formulir ditetapkan ke halaman persis seperti tampilannya. Pemisahan dan penamaan berdasarkan teks memerlukan teks yang dapat diekstrak. Hasil pindai dan tulisan tangan tidak diproses dengan OCR. PDF bertanda tangan dan formulir dinamis (XFA) tidak didukung.

Bagaimana aturan berbasis teks bekerja?

Tandai area ID pada halaman yang mewakili tata letak dokumen. Halaman berurutan dengan ID yang sama tetap digabungkan. Tandai area kedua untuk nama file. Periksa setiap hasil, terutama jika tata letak halaman berbeda. Area yang berbeda atau ID yang sama dapat menyebabkan pengelompokan yang salah.

Apakah file asli dan keluaran identik?

File asli tidak diubah. Halaman keluaran disalin ke PDF baru. Tampilan halaman diupayakan tetap sama; bookmark tingkat dokumen, metadata, tautan antarahalaman, dan tag aksesibilitas dapat berubah atau hilang. Simpan file asli dan periksa keluaran Anda.

Apakah saya perlu akun atau langganan?

Demo browser gratis. Versi Windows dijual terpisah dengan pembelian satu kali. Pengembalian dana tersedia dalam 14 hari setelah pembelian, tanpa pertanyaan. Versi yang Anda unduh tidak kedaluwarsa. Versi utama mendatang dan penyiapan dokumen khusus tidak termasuk.

Mengapa nama file berubah?

Karakter yang tidak aman untuk sistem file umum diganti. Nama panjang dipersingkat, dan nama duplikat diberi akhiran angka. Edit nama file yang diusulkan sebelum menyimpan. Setiap penyimpanan menyertakan manifest.json dengan pemetaan akhir halaman ke file.

Apakah saya dapat memproses beberapa PDF sekaligus?

Ya. Buka hingga 20 PDF bersamaan. Aturan yang sama berlaku untuk setiap file, dan setiap file mendapat subfolder sendiri. Tandai area pada file yang representatif dan periksa setiap hasil sebelum menyimpan.
