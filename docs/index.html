구매 전에 호환성을 확인하세요

최신 Chrome 또는 Edge가 설치된 Windows가 필요합니다. 정적 PDF와 입력칸이 있는 양식 PDF를 지원합니다(입력값은 보이는 그대로 페이지에 고정). 스캔본은 페이지 기준으로 분리할 수 있지만 OCR이나 손글씨 인식은 제공하지 않습니다. 암호화·전자서명·동적 양식(XFA) PDF와 첨부 파일·실행 동작이 있는 파일은 처리하지 않습니다. 책갈피와 접근성 태그의 보존은 보장하지 않습니다.

자주 묻는 질문

PDF가 내 기기 밖으로 전송되나요?

PDF 처리는 브라우저 안에서 이루어집니다. 이 앱은 문서나 문서의 텍스트를 업로드하지 않습니다. 호스팅 업체는 일반적인 웹페이지 요청을 처리합니다. 분석 및 광고 스크립트는 포함되어 있지 않습니다.

이 버전은 무엇을 지원하나요?

정적 PDF와 입력 가능한 양식을 페이지 수나 지정 범위로 분리할 수 있습니다. 양식 필드는 화면에 보이는 그대로 페이지에 고정됩니다. 텍스트 기준 분리와 이름 지정에는 추출 가능한 텍스트가 필요합니다. 스캔본과 손글씨의 OCR 처리는 제공하지 않습니다. 서명된 PDF와 동적(XFA) 양식은 지원하지 않습니다.

텍스트 기준 규칙은 어떻게 작동하나요?

대표 페이지에서 ID 영역을 선택하세요. 같은 ID의 연속 페이지는 하나로 묶입니다. 파일명에 사용할 영역을 별도로 선택하세요. 페이지 배치가 다르면 특히 모든 결과를 확인해야 합니다. 서로 다른 영역이나 동일한 ID 때문에 잘못 묶일 수 있습니다.

원본과 출력 파일은 동일한가요?

원본 파일은 바뀌지 않습니다. 출력 페이지는 새 PDF에 복사됩니다. 페이지 모양을 유지하도록 처리하지만, 문서 수준의 책갈피, 메타데이터, 페이지 간 링크 및 접근성 태그는 바뀌거나 없어질 수 있습니다. 원본을 보관하고 출력 파일을 확인하세요.

계정이나 구독이 필요한가요?

브라우저 데모는 무료입니다. Windows 버전은 별도로 한 번 구매하는 제품입니다. 구매 후 14일 안에는 이유를 묻지 않고 환불해 드립니다. 다운로드한 버전에는 사용 기한이 없습니다. 향후 주요 버전과 개인별 문서 설정 서비스는 포함되지 않습니다.

파일명이 바뀐 이유는 무엇인가요?

일반적인 파일 시스템에서 안전하지 않은 문자는 대체됩니다. 긴 이름은 줄이고 중복된 이름에는 번호를 붙입니다. 저장 전에 제안된 파일명을 수정할 수 있습니다. 저장할 때마다 최종 페이지별 파일 대응표인 manifest.json이 함께 포함됩니다.

여러 PDF를 한 번에 처리할 수 있나요?

네. 최대 20개의 PDF를 함께 열 수 있습니다. 모든 파일에 같은 규칙이 적용되며 파일마다 별도의 하위 폴더가 만들어집니다. 대표 파일에서 영역을 지정하고, 저장하기 전에 모든 결과를 확인하세요.
