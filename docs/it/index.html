Le risposte prima ancora delle domande

Il mio PDF lascia questo dispositivo?

L’elaborazione del PDF avviene localmente nel browser. Questa app non carica il documento né il suo testo su un server. Il fornitore di hosting gestisce comunque le normali richieste della pagina. Non sono inclusi script di analisi del traffico o pubblicità.

Cosa funziona in questa versione?

I PDF statici e i moduli compilabili possono essere divisi per numero di pagine o intervalli espliciti. I campi dei moduli vengono fissati nella pagina esattamente come appaiono. La divisione e i nomi basati sul testo richiedono testo estraibile. Scansioni e scrittura a mano non vengono elaborate tramite OCR. I PDF firmati e i moduli dinamici (XFA) non sono supportati.

Come funzionano le regole basate sul testo?

Traccia l’area dell’ID su una pagina rappresentativa. Le pagine consecutive con lo stesso ID restano insieme. Traccia una seconda area per il nome del file. Controlla ogni risultato, soprattutto quando cambia l’impaginazione. Aree diverse o ID identici possono causare raggruppamenti errati.

L’originale e il risultato sono identici?

Il file originale resta invariato. Le pagine di output vengono copiate in nuovi PDF. Si punta a conservarne l’aspetto; segnalibri, metadati, collegamenti tra pagine e tag di accessibilità del documento possono cambiare o andare persi. Conserva l’originale e controlla i risultati.

Serve un account o un abbonamento?

La demo nel browser è gratuita. La versione Windows è un acquisto unico separato. Puoi ottenere il rimborso entro 14 giorni dall’acquisto, senza dover fornire motivazioni. La versione scaricata non scade. Non sono incluse le future versioni principali né la configurazione personalizzata dei documenti.

Perché un nome di file è cambiato?

I caratteri non adatti ai file system più comuni vengono sostituiti. I nomi lunghi vengono accorciati e i duplicati ricevono un suffisso numerato. Puoi modificare qualsiasi nome proposto prima di salvare. Ogni salvataggio include manifest.json con la corrispondenza finale tra pagine e file.

Posso elaborare più PDF insieme?

Sì. Apri fino a 20 PDF insieme. Le stesse regole valgono per ogni file e ciascun file ha la propria sottocartella. Traccia le aree su un file rappresentativo e controlla ogni risultato prima di salvare.
