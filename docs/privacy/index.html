Privacy information

Updated 17 October 2026.

Document processing

PDF files, selected text regions, extracted text, filenames and generated outputs are processed in your browser. Paperlane's application code does not upload these document contents to a server or AI service. Saved rule files are downloaded to your device when you request them.

Website visits

This website is hosted on GitHub Pages. Your browser requests the pages and assets from GitHub, which can receive ordinary request information, including IP address and browser information, under its own policies. Paperlane includes no advertising tracker or third-party analytics script. The tool stores your language preference in browser local storage; clearing website data removes it.

Downloaded version

The Windows package serves the included files on a loopback address (127.0.0.1) on your own PC and has no upload feature. It does not require internet access after download. Your browser, extensions, operating system and any synchronized folders have their own privacy behavior, which this tool cannot control.

Checkout

Checkout opens on Lemon Squeezy, which acts as the merchant of record and handles payment information, orders, receipts and download delivery under its privacy policy. We receive the order details needed to support your purchase. We do not collect newsletter subscriptions or contact form submissions. Questions: b0crv2@gmail.com.
