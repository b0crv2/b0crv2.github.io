เปิด PDF ได้สูงสุด 20 ไฟล์พร้อมกันบนพีซีของคุณ (ไฟล์ละไม่เกิน 50 MB และ 300 หน้า) รองรับแบบฟอร์มที่กรอกได้ บันทึกลงโฟลเดอร์ใหม่หรือ ZIP ได้ทันที และนำกฎกลับมาใช้ซ้ำได้ หลังดาวน์โหลดไม่ต้องใช้อินเทอร์เน็ต

ซื้อรุ่น Windows

หลังยืนยันการชำระเงิน ผู้ให้บริการชำระเงินจะจัดส่งไฟล์ดาวน์โหลดและใบเสร็จให้อัตโนมัติ

ตรวจสอบความเข้ากันได้ก่อนซื้อ

Windows พร้อม Chrome หรือ Edge รุ่นปัจจุบัน รองรับ PDF แบบคงที่และแบบฟอร์มที่กรอกได้ (ค่าในช่องจะถูกตรึงลงในหน้าตามที่แสดง) ไฟล์สแกนแยกตามหน้าได้ แต่ไม่มี OCR หรือการรู้จำลายมือ ไม่รับ PDF ที่เข้ารหัส มีลายเซ็นดิจิทัล หรือเป็นแบบไดนามิก (XFA) รวมถึงไฟล์ที่มีไฟล์แนบหรือเนื้อหาที่ทำงานได้ ไม่รับประกันการคงบุ๊กมาร์กและแท็กการช่วยการเข้าถึง

คำตอบก่อนที่คุณจะต้องถาม

PDF จะถูกส่งออกจากอุปกรณ์นี้หรือไม่?

การประมวลผล PDF ทำงานภายในเบราว์เซอร์ แอปนี้ไม่อัปโหลดเอกสารหรือข้อความในเอกสาร ผู้ให้บริการโฮสติ้งยังคงจัดการคำขอหน้าเว็บตามปกติ ไม่มีสคริปต์วิเคราะห์หรือโฆษณา

รุ่นนี้รองรับอะไรบ้าง?

PDF แบบคงที่และแบบฟอร์มที่กรอกได้สามารถแยกตามจำนวนหน้าหรือช่วงที่ระบุได้ ช่องแบบฟอร์มจะถูกตรึงลงในหน้าตามที่แสดงอยู่ทุกประการ การแยกและตั้งชื่อจากข้อความต้องมีข้อความที่ดึงออกมาได้ ไม่มีการทำ OCR ให้ไฟล์สแกนหรือข้อความลายมือ ไม่รองรับ PDF ที่มีลายเซ็นและแบบฟอร์มไดนามิก (XFA)

กฎที่ใช้ข้อความทำงานอย่างไร?

ลากกรอบรหัสบนหน้าที่ใช้เป็นตัวแทน หน้าต่อเนื่องที่มีรหัสเดียวกันจะรวมอยู่ด้วยกัน ลากกรอบที่สองสำหรับชื่อไฟล์ ตรวจสอบผลลัพธ์ทุกรายการ โดยเฉพาะเมื่อรูปแบบหน้าแตกต่างกัน พื้นที่ที่ต่างกันหรือรหัสที่เหมือนกันอาจทำให้จัดกลุ่มผิด

ต้นฉบับกับผลลัพธ์เหมือนกันทุกประการหรือไม่?

ไฟล์ต้นฉบับไม่เปลี่ยนแปลง หน้าผลลัพธ์จะถูกคัดลอกไปยัง PDF ใหม่ โดยพยายามรักษาลักษณะหน้าตาเดิมไว้ แต่บุ๊กมาร์กระดับเอกสาร เมทาดาทา ลิงก์ระหว่างหน้า และแท็กการช่วยการเข้าถึงอาจเปลี่ยนแปลงหรือหายไป โปรดเก็บต้นฉบับและตรวจสอบผลลัพธ์

ต้องมีบัญชีหรือสมัครสมาชิกหรือไม่?

เดโมในเบราว์เซอร์ใช้ได้ฟรี รุ่น Windows เป็นสินค้าซื้อแยกแบบจ่ายครั้งเดียว ขอคืนเงินได้ภายใน 14 วันหลังซื้อโดยไม่ต้องแจ้งเหตุผล รุ่นที่ดาวน์โหลดจะไม่หมดอายุ ไม่รวมรุ่นหลักใหม่ในอนาคตหรือบริการตั้งค่าเอกสารเฉพาะบุคคล

ทำไมชื่อไฟล์จึงเปลี่ยนไป?

อักขระที่ไม่ปลอดภัยสำหรับระบบไฟล์ทั่วไปจะถูกแทนที่ ชื่อที่ยาวจะถูกย่อ และชื่อซ้ำจะเติมเลขต่อท้าย คุณแก้ไขชื่อไฟล์ที่เสนอไว้ได้ก่อนบันทึก การบันทึกทุกครั้งจะมี manifest.json ซึ่งระบุการจับคู่หน้ากับไฟล์ขั้นสุดท้าย

ประมวลผลหลาย PDF พร้อมกันได้หรือไม่?

ได้ เปิดได้สูงสุด 20 PDF พร้อมกัน กฎเดียวกันจะใช้กับทุกไฟล์ และแต่ละไฟล์จะมีโฟลเดอร์ย่อยของตัวเอง วาดพื้นที่บนไฟล์ที่เป็นตัวแทน แล้วตรวจสอบผลลัพธ์ทุกรายการก่อนบันทึก
