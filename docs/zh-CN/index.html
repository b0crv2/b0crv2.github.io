常见问题

我的 PDF 会离开这台设备吗？

PDF 在浏览器本地处理。本应用不会上传文档或其中的文字。托管服务商仍会处理普通网页请求。不含分析或广告脚本。

此版本支持哪些功能？

静态 PDF 和可填写表单可按页数或指定范围拆分。表单字段会按其显示效果固定到页面中。按文字拆分和命名需要 PDF 含有可提取的文字。不对扫描件或手写内容进行 OCR 识别。不支持已签名的 PDF 和动态（XFA）表单。

文字规则如何工作？

在具有代表性的页面上框选编号区域。编号相同的连续页面会归为一份文档。再选择一个区域用于文件名。请检查每项结果，尤其是页面布局不一致时。区域不同或编号相同可能导致错误分组。

原件和输出文件完全一样吗？

原始文件保持不变。页面会被复制到新 PDF 中。处理过程旨在保留页面外观，但文档级书签、元数据、页面间链接和无障碍标签可能改变或丢失。请保留原件并检查输出文件。

需要账户或订阅吗？

浏览器演示版免费。Windows 版需单独一次性购买。购买后 14 天内可无理由退款。下载的版本没有使用期限。不包含未来的主要版本或个性化文档设置服务。

为什么文件名发生了变化？

常见文件系统中不安全的字符会被替换。过长的名称会缩短，重名文件会添加数字后缀。保存前可编辑所有拟定文件名。每次保存都会包含 manifest.json，记录最终页面与文件的对应关系。

可以一次处理多个 PDF 吗？

可以。最多可同时打开 20 个 PDF。相同规则将应用于所有文件，每个文件都有自己的子文件夹。请在有代表性的文件上绘制区域，并在保存前检查所有结果。
