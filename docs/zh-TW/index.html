常見問題

我的 PDF 會離開這台裝置嗎？

PDF 在瀏覽器本機處理。本應用程式不會上傳文件或其中的文字。代管服務商仍會處理一般網頁請求。不含分析或廣告指令碼。

此版本支援哪些功能？

靜態 PDF 和可填寫表單可依頁數或指定範圍分割。表單欄位會依其顯示外觀固定到頁面中。依文字分割和命名需要 PDF 含有可擷取的文字。不對掃描檔或手寫內容進行 OCR 辨識。不支援已簽章的 PDF 和動態（XFA）表單。

文字規則如何運作？

在具有代表性的頁面上框選編號區域。編號相同的連續頁面會歸為一份文件。再選取另一個區域用於檔名。請檢查每項結果，尤其是頁面配置不一致時。區域不同或編號相同可能導致分組錯誤。

原始檔案和輸出檔案完全一樣嗎？

原始檔案保持不變。頁面會被複製到新 PDF 中。處理過程旨在保留頁面外觀，但文件層級的書籤、中繼資料、頁面間連結和無障礙標籤可能改變或遺失。請保留原始檔案並檢查輸出。

需要帳號或訂閱嗎？

瀏覽器示範版免費。Windows 版需另外一次購買。購買後 14 天內可無條件退款。下載的版本沒有使用期限。不包含未來的主要版本或個人化文件設定服務。

為什麼檔名改變了？

常見檔案系統中不安全的字元會被替換。過長的名稱會縮短，重名檔案會加上數字後綴。儲存前可編輯所有預定檔名。每次儲存都會包含 manifest.json，記錄最終頁面與檔案的對應關係。

可以一次處理多個 PDF 嗎？

可以。最多可同時開啟 20 個 PDF。相同規則會套用到所有檔案，每個檔案都有自己的子資料夾。請在具代表性的檔案上繪製區域，並在儲存前檢查所有結果。
